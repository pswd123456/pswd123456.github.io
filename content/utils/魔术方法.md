## 双下划线方法 (Dunder Methods) 🪄

"Dunder" 是 "Double Underscore"（双下划线）的缩写。在 Python 中，以双下划线开头和结尾的方法（例如 `__init__`, `__str__`, `__or__`）被称为**魔术方法 (Magic Methods)**。

- **它的作用**：它允许你定义的类（Class）去模拟 Python 内置类型的行为，特别是**运算符重载 (Operator Overloading)**。
    
- **在 LangChain 中的应用**：
    
    - **`__or__`**: 对应按位或运算符 `|`。LangChain 借用了这个符号，赋予了它“连接”的语义（就像 Unix 管道一样）。在 `Runnable` 类中，`__or__` 方法检测到右边的对象后，会把它们打包进 `RunnableSequence`。
        
    - **`__init__`**: 构造函数，用于初始化对象。
        
    - **`__repr__`**: 定义对象的字符串表示，当你打印一个 Chain 时，能看到清晰的结构就是它的功劳。
        

> 💡 **简单来说**：魔术方法让你的对象可以用 `+`, `-`, `|`, `len()` 等标准语法来操作，让代码更简洁、更像原生 Python 对象。
