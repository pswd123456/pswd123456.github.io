## Ragas 测试集生成：第四步结果导出与使用 (Export and Use) 源码解析

这是流程的最后一步。当你成功运行了生成器后，你会得到一个 `Testset` 对象。这一步的核心任务是将这个内存中的对象转换为**可存储的文件**（如 CSV/JSON）或**可直接用于评估的数据集**。

### 1. 核心结果对象：`Testset`

**源码片段：**

```Python
@dataclass
class Testset(RagasDataset[TestsetSample]):
    """
    Represents a test set containing multiple test samples.
    """
    samples: t.List[TestsetSample]
    # ...

    def to_list(self) -> t.List[t.Dict]:
        """
        Converts the Testset to a list of dictionaries.
        """
        list_dict = []
        for sample in self.samples:
            sample_dict = sample.eval_sample.model_dump(exclude_none=True)
            sample_dict["synthesizer_name"] = sample.synthesizer_name
            list_dict.append(sample_dict)
        return list_dict
```

**解读：**

- `Testset` 是一个容器，里面装着很多 `TestsetSample`。
    
- 每个样本不仅包含题目和答案（在 `eval_sample` 中），还包含一个重要的元数据：`synthesizer_name`。这能让你知道这个问题是由哪个合成器生成的（是单跳简单题，还是多跳推理题），方便后续分析数据分布。

---

### 2. 最常用的操作：转换为 Pandas DataFrame

源码中提供的 `to_list()` 方法是为了方便用户将数据转换为 Python 原生字典列表，而这正是构建 Pandas DataFrame 的标准输入格式。

**如何使用：**

```Python
import pandas as pd

# 假设 testset 是 generate() 的返回结果
# 1. 转为 DataFrame
df = pd.DataFrame(testset.to_list())

# 2. 查看列名，通常包含：
# - user_input: 生成的问题
# - reference: 标准答案
# - reference_contexts: 生成答案所依据的文档片段
# - synthesizer_name: 题目类型 (例如 'single_hop_specific_query_synthesizer')
print(df.head())

# 3. 保存为 CSV 或 Excel
df.to_csv("my_ragas_testset.csv", index=False)
```

**为什么推荐这样做？**

- **便于人工清洗**：生成的测试集可能包含少量不完美的问题。导出为 Excel 后，你可以人工快速筛选、修改。
    
- **持久化**：将耗时生成的测试集保存下来，下次跑评估时直接加载，不用重新生成。

---

### 3. 直接用于评估：转换为 `EvaluationDataset`

如果你生成测试集是为了立刻测试4你的 RAG 管道（Pipeline），Ragas 提供了一个快捷通道。

**源码片段：**

```Python
    def to_evaluation_dataset(self) -> EvaluationDataset:
        """
        Converts the Testset to an EvaluationDataset.
        """
        return EvaluationDataset(
            samples=[sample.eval_sample for sample in self.samples]
        )
```

解读：

EvaluationDataset 是 Ragas 评估模块（ragas.evaluate）所需要的标准输入格式。这个方法剥离了生成过程的元数据（如 synthesizer_name），只保留评估所需的字段。

**如何使用：**

```Python
from ragas import evaluate
from ragas.metrics import faithfulness, answer_relevancy

# 1. 转换格式
eval_dataset = testset.to_evaluation_dataset()

# 2. 结合你的 RAG 管道结果进行评估
# 注意：这里通常需要你先用生成的 questions 去跑一遍你的 RAG 系统，
# 得到 contexts 和 answer，然后更新到 dataset 中。
# (这一步属于评估流程，超出了生成模块的范畴)
```

### 4. 加载已保存的数据

如果你之前保存了 CSV，或者想加载外部标注好的数据，源码提供了 `from_list` 或 `from_annotated` 方法。

**源码片段：**

```Python
    @classmethod
    def from_list(cls, data: t.List[t.Dict]) -> Testset:
        """
        Converts a list of dictionaries to a Testset.
        """
        samples = []
        for sample in data:
            # 自动识别是单轮对话还是多轮对话
            # ...
            samples.append(TestsetSample(...))
        return Testset(samples=samples)
```

**如何使用：**

```Python
import pandas as pd
from ragas.testset import Testset

# 1. 从 CSV 读取
df_new = pd.read_csv("my_ragas_testset.csv")

# 2. 还原为 Testset 对象
# 注意：pandas 读取后 NaN 值处理可能需要注意，确保格式符合 dict 要求
loaded_testset = Testset.from_list(df_new.to_dict("records"))
```

## 全流程总结 (Cheatsheet)

作为库的使用者，Ragas 测试集生成的完整代码模板如下：

```Python
from ragas.testset import TestsetGenerator
from langchain_openai import ChatOpenAI, OpenAIEmbeddings
from langchain_community.document_loaders import PyPDFLoader
import pandas as pd

# 1. 初始化 (Initialization)
generator = TestsetGenerator.from_langchain(
    llm=ChatOpenAI(model="gpt-4"),
    embedding_model=OpenAIEmbeddings()
)

# 2. 数据准备 (Data Preparation)
loader = PyPDFLoader("data.pdf")
documents = loader.load()

# 3. 执行生成 (Execution)
# 这一步最耗时，建议先用小 size (如 2) 测试
testset = generator.generate_with_langchain_docs(
    documents=documents,
    testset_size=10,
    raise_exceptions=False
)

# 4. 结果导出 (Export)
df = pd.DataFrame(testset.to_list())
df.to_csv("generated_testset.csv", index=False)
print(f"成功生成 {len(df)} 条测试数据！")
```

这就是 Ragas 生成模块的完整学习路线。它通过高度封装的 API (`TestsetGenerator`) 隐藏了底层的知识图谱构建 (`Transforms`) 和 复杂的查询合成逻辑 (`Synthesizers`)，让用户可以像使用普通函数一样生成高质量的测试数据。
