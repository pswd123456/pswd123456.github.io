这一阶段的目标是学会如何“搭建”一个 LangGraph 应用。LangGraph 的核心理念是：**图（Graph）是流程的骨架，状态（State）是流动的血液。**

你需要关注的核心类是 `StateGraph`，以及两个关键常量 `START` 和 `END`。

以下是详细的拆解：

## 1. 定义状态 (State)

在创建图之前，必须先定义“状态”。状态是一个数据结构（通常是 `TypedDict` 或 `Pydantic` 模型），它是图中所有节点共享的内存。

- **作用**: 节点读取状态作为输入，并返回状态的更新（Partial Update）作为输出。
    
- **代码位置**: 虽然用户通常自己定义，但 LangGraph 提供了一些辅助工具，如 `MessagesState`。
    

**示例 (定义一个简单的计数器状态):**

```Python
from typing import TypedDict

class MyState(TypedDict):
    count: int
    user_input: str
```

## 2. 初始化图 (StateGraph)

`StateGraph` 是构建图的画布。

- **初始化**: 必须传入 `state_schema`（即上面定义的状态类）。

    ```Python
    from langgraph.graph import StateGraph
    
    builder = StateGraph(MyState)
    ```

## 3. 添加节点 (Nodes)

节点是执行具体逻辑的地方（比如调用 LLM、查询数据库、执行计算）。

- **函数签名**: 节点的函数接收当前 `State`，并返回要更新的字段字典。
    
- **注册**: 使用 `add_node(name, function)` 方法。
    

**代码示例:**

```Python
def process_input(state: MyState):
    # 逻辑：将输入转大写
    return {"user_input": state["user_input"].upper()}

def increment_count(state: MyState):
    # 逻辑：计数加一
    return {"count": state["count"] + 1}

# 将函数注册为图中的节点
builder.add_node("processor", process_input)
builder.add_node("counter", increment_count)
```

## 4. 添加边 (Edges)

边定义了节点执行的顺序（控制流）。

- **基础常量**: `START` 代表图的入口，`END` 代表图的结束。
    
- **普通边**: `add_edge(from_node, to_node)` 表示节点 A 执行完后，立即执行节点 B。
    
- **入口点**: `set_entry_point(node_name)` 等同于 `add_edge(START, node_name)`。
    
- **条件边**: `add_conditional_edges` 允许根据状态内容动态决定下一个节点（例如：如果 LLM 返回工具调用，则去工具节点；否则结束）。
    

**代码示例:**

```Python
from langgraph.graph import START, END

# 设置起点：图开始运行时，首先执行 processor
builder.add_edge(START, "processor")

# processor 执行完后，执行 counter
builder.add_edge("processor", "counter")

# counter 执行完后，流程结束
builder.add_edge("counter", END)
```

## 5. 编译 (Compile)

这是最后一步。定义好节点和边后，必须调用 `.compile()`。

- **作用**: 它将图的定义转换为一个可执行的 `CompiledStateGraph`（它本质上是一个 Runnable）。
    
- **结果**: 编译后的对象拥有 `.invoke`, `.stream` 等标准 Runnable 方法。

```Python

graph = builder.compile()
```

## 实战演练：Hello World

让我们把上面的碎片拼成一个完整的、可运行的例子。

```Python
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

# 1. 定义状态
class State(TypedDict):
    name: str
    message: str

# 2. 定义节点逻辑
def greeter(state: State):
    return {"message": f"Hello, {state['name']}!"}

def appender(state: State):
    return {"message": state['message'] + " Welcome to LangGraph."}

# 3. 初始化图
builder = StateGraph(State)

# 4. 添加节点
builder.add_node("greet_node", greeter)
builder.add_node("append_node", appender)

# 5. 定义流向 (边)
builder.add_edge(START, "greet_node")      # 开始 -> 问候
builder.add_edge("greet_node", "append_node") # 问候 -> 追加信息
builder.add_edge("append_node", END)       # 追加信息 -> 结束

# 6. 编译
app = builder.compile()

# 7. 运行
result = app.invoke({"name": "Alice"})
print(result)
# 预期输出: {'name': 'Alice', 'message': 'Hello, Alice! Welcome to LangGraph.'}
```

## 总结与下一步

在这一阶段，你已经学会了：

1. 使用 `TypedDict` 定义图的内存结构。
    
2. 使用 `StateGraph` 创建图。
    
3. 通过 `add_node` 和 `add_edge` 编排简单的顺序工作流。
    
4. 使用 `compile` 获取可执行对象。
    

**潜在问题**: 你可能会发现，如果多次运行节点，状态是直接被“覆盖”的（例如 `count` 总是被设为新值，而不是累加）。这是因为默认的通道行为是 `LastValue`（保留最后一个值）。
